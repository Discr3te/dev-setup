# Arch setup

This is a setup script that install all the packages I use and symlinks my dotfiles

## Setup

Run this line on a fresh installed Arch (btw) OS and it will do the rest.

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Discr3te/dev-setup/refs/heads/main/setup)"
```

After its finished, setup your yubikey and ssh stuff using the scripts in `~/.local/bin`
